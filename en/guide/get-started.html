Quick Start

From download to your first match in just a few steps.

Installing the Software

Warning
If you are in mainland China or cannot access the following page, please use a proxy!
  • Choose the download link for your operating system (each link downloads the matching archive directly):
    • Windows (64-bit): windows_amd64
    • macOS (Apple Silicon / M-series): macOS_arm64
    • macOS (Intel): macOS_amd64
    • Linux (x86_64): linux_amd64
    • Linux (arm64): linux_arm64
  • After downloading, extract the archive and run the application; once running, the Archer window will open automatically and display the interface.

Starting the Software

The startup method may vary based on your operating system.

  • Windows: Double-click archer.exe to run it.
    • To keep the log open, open the terminal, navigate to the extracted directory, and enter start /K archer.exe.
  • Linux: Open the terminal, navigate to the extracted directory, and enter ./archer to run the program.
  • macOS: Open the terminal, navigate to the extracted directory, and enter ./archer to run the program.

Getting Started

  1. In the Archer window that opens, click 【Account Information】 on the left side.
  2. Click the 【Register】 button.
    • If you've already registered, just enter your existing ID and click 【Save】 on the right.
  3. Click the 【Save】 button.
  4. Click the 【🚀】 button to log in.
  5. After logging in successfully, a game window will pop up. Log into your game account in this window.
  6. Once the game login is complete, go to the 【Account Information】 page in the Archer window and enter the 【Redemption Code】, then click the 【Redeem】 button.
  7. After completing these steps, you can start a match.
