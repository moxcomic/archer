基础知识

二次开发前需要了解的开发语言、环境与文件路径。

开发语言

  • Golang

语言版本

  • Go 1.20+ < 1.23

开发环境

  • 无需安装任何环境

开发工具

以下任选其一：

  • Visual Studio Code
  • Intellij IDEA
  • Sublime Text
  • Notepad++

文件路径

  • Archer目录/scripts/auto.go
