脚本包路径迁移指南

通过 /auto 接口下发远端 Go 脚本的开发者，以及维护本地 scripts/*.majsoul 样本的人，都需要按本指南更新脚本里的 import 路径。

注意

适用对象：通过 /auto 接口下发远端 Go 脚本的开发者，以及维护本地 scripts/*.majsoul 样本的人。

本次重构把脚本可见的 Go 包搬进了 internal/ 分层目录。你脚本里的 import 路径需要更新，否则 Go 脚本在加载/运行时会报 unable to find source / undefined symbol。

警告
⚠️ 2026 更新（雀魂 Unity 迁移）：雀魂网页版改用 Unity + WASM 后，所有查询 LayaBox UI 状态的“管理器”包已被整体移除：lobbymgr、desktopmgr、infomgr、gameendmgr、activitymgr、activitysignmgr、monthlymgr、countdown、playerinfo。它们依赖的 LayaBox 引擎 JS 全局对象在 Unity 下不存在。下文 A 表中的这些 widget 行、以及 B2 / B3 小节均已失效，请勿再使用；游戏状态判断请改为基于对局 protobuf 事件流推导。其余包（gamestate / userinfo / variable / actions 等）与 utils 拆分（B1）不受影响。
警告
⚠️ 2026-10 更新（通知改用 nikoksr/notify）：适用于包含本次改动的新版 Archer；仍在使用旧版客户端的，本地脚本里的 pusher 照旧可用；/auto 远端脚本的规则不分版本，需要在新版发布之前完成。新版中 pusher 以及 discord / telegram / wechat 包已删除：本地脚本发通知改用 notify.Inst().SendText(...)；/auto 远端脚本删除 pusher 的 import 和调用，不要换成 notify。详见下文 C 节。

一句话总结

  • 绝大多数包：只改 import 路径，包名.Inst().方法() 的调用写法完全不变。
  • utils 拆成 4 个包（去掉 .Inst()，改用包级函数，见 B1）。（原先合并出的 countdown / playerinfo 等 UI 状态查询包已随 Unity 迁移移除，见上方提示。）
  • 通知改用 notify.Inst().SendText（见 C 节）：pusher / discord / telegram / wechat 包已删除；/auto 远端脚本不得 import internal/notify 下的任何包。
  • A 表里的包方法名一律不变。config 路径不变。引擎包 github.com/moxcomic/lq、github.com/moxcomic/engine/tenhou_client 不受影响。

为什么会变

Go 脚本解释器靠一张 symbols 符号表把脚本里的 import 路径映射到真实的 Go 包。重构后这些包的物理位置（import 路径）变了，symbols 表已随之同步更新；但你脚本里写死的 import 路径需要你手动改——路径对不上，解释器 找不到对应符号，就会在加载或运行时报错。

C. 通知接口（2026-10 起，pusher 已删除）

本节适用于包含本次改动的新版 Archer；仍在使用旧版客户端的，本地脚本里的 pusher 照旧可用；/auto 远端脚本的规则不分版本，需要在新版发布之前完成。

Archer 的推送改用 nikoksr/notify，设置页的“通知”里可以勾选 30 多个渠道。客户端本地脚本里发通知只用一个接口 （/auto 远端脚本的改法不同，见表下说明）：

旧写法新写法
import "github.com/moxcomic/Archer/internal/notify/pusher"
（或更早的 github.com/moxcomic/Archer/pusher）		import "github.com/moxcomic/Archer/internal/notify"
pusher.Inst().SendMasterText(text)notify.Inst().SendText(text)
pusher.Inst().SendMasterImages(...)删除（不再支持发图）
func onWeChatMessage(value string) / onDingtalkMessage新版不再调用，本地脚本可删除（个人微信、钉钉 Stream 机器人渠道已移除）
func onTelegramMessage(value string) / onDiscordMessage不变
  • SendText 发给设置页里勾选、并且勾了“脚本消息”的渠道；调用立即返回，后台发送。
  • 手机指令只在 Telegram、Discord 上可用：先给机器人发 ping 绑定会话，之后只有已绑定的会话发来的文字才会交给 onTelegramMessage / onDiscordMessage。screenshot 指令已移除。
  • 升级到新版后需要重新给机器人发一次 ping：旧版的绑定从未保存到磁盘。
  • 只有接收人列表为空时，ping 才会自动绑定；列表非空时，陌生会话发来的 ping 会被忽略，需要在设置页手动添加会话 ID。
  • Discord 需要在开发者后台为机器人打开 Message Content Intent，否则机器人连不上网关（会被以 4014 关闭），收不到任何指令；发送通知不受影响。
  • discord、telegram、wechat 包已删除，脚本不能再直接调用它们。
  • /auto 下发的远端脚本不分客户端版本，不得 import internal/notify 下的任何包：新旧客户端没有一个同时都有的通知包（旧版提供的是 internal/notify/pusher，新版提供的是 internal/notify），哪一边缺符号都会让整份脚本加载失败。正确改法：删除 pusher 的 import 和全部调用，不要换成 notify；服务端脚本不再发送指令回执，需要发通知的逻辑放到客户端本地脚本里。

迁移检查清单

  1. 把脚本里所有 github.com/moxcomic/Archer/<X> 的 import 按 A 表替换为 internal/... 路径。
  2. 本地脚本（scripts/auto.go 等客户端本地加载的脚本；scripts/*.majsoul 样本的内容也按这种写法）：把 pusher.Inst().SendMasterText(...) 改成 notify.Inst().SendText(...)（见 C 节），删除 SendMasterImages 调用；新版不再调用 onWeChatMessage / onDingtalkMessage，可一并删除。
  3. /auto 远端脚本：删除 pusher 的 import 和全部调用，不要换成 notify（服务端脚本不再发送指令回执，需要发通知的逻辑放到本地脚本）。 onWeChatMessage / onDingtalkMessage 可保留：新版客户端不再调用，旧版客户端仍靠它们响应微信/钉钉指令。 scripts/*.majsoul 样本是给 /auto 开发者参考的，但内容按本地脚本写法使用 notify，照着它写 /auto 脚本时必须删掉通知相关的 import 与调用。
  4. utils.Inst().X() → 按 B1 改成 engineswitch / botdispatch / pagecontrol / extension 对应的包级函数（去掉 Inst().）。
  5. winmgr / huleshowmgr / scorechangemgr / playerinfomgr / otherplayerinfomgr 等 UI 状态查询包 → 已随 Unity 迁移移除，请删除相关调用，改为基于对局事件流判断状态。
  6. config、github.com/moxcomic/lq、github.com/moxcomic/engine/tenhou_client 保持不变。
  7. 若用过 userinfo.Inst().IsVaild()，改为 IsValid()。
  8. 确认 /auto 脚本里没有 import internal/notify 下的任何包后，重新部署到 /auto 下发端。scripts/*.majsoul 样本按本地脚本写法使用 notify，参考它写 /auto 脚本时必须删掉通知相关的 import 与调用。
注意
本地实际加载的脚本 scripts/auto.go 已随重构同步更新并通过 Go 脚本 加载测试。远端 /auto 下发的脚本需要你按本指南更新。
